# URL Shortener

Generated by the agentic SDLC orchestrator. See `docs/requirements.md`, `docs/architecture.md` and `docs/plan.md` for how this came to be built this way.

## Run it

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Test it

```bash
pip install pytest httpx2 httpx
pytest
```

## API

| Method | Path | Description |
|---|---|---|
| POST | `/api/urls` | create a shortened URL |
| GET | `/{code}` | redirect to the original long URL |
| GET | `/api/urls/{code}` | fetch metadata for a code |
| DELETE | `/api/urls/{code}` | revoke a code |
| GET | `/api/urls/{code}/stats` | click analytics for a code |
| GET | `/health` | liveness check |

## Capabilities in this build
- alias: enabled
- expiry: enabled
- stats: enabled
- rate_limit: enabled
